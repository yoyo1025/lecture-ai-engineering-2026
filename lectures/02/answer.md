## 宿題

### 基礎課題

#### 取り組んだレベル

基礎レベルに取り組んだ。LoRA のランク `lora_r` を変更し、学習結果を比較した。

#### 変えた設定やデータ

ベースモデルや学習データは変更せず、`lora_r` のみを変更した。

| 設定 | `lora_r = 16` | `lora_r = 8` |
|---|---:|---:|
| ベースモデル | Qwen/Qwen3.5-0.8B | Qwen/Qwen3.5-0.8B |
| 学習率 | 0.0002 | 0.0002 |
| エポック数 | 20 | 20 |
| ステップ数 | 40 | 40 |
| LoRA alpha | 32 | 32 |
| 最大系列長 | 512 | 512 |
| 量子化 | なし | なし |
| 生成方法 | do_sample=True | do_sample=True |

`lora_r = 16` の学習可能パラメータ数は約 639 万個、全体に占める割合は約 0.8421% だった。

`lora_r = 8` では学習可能パラメータ数が約 319 万個、割合は約 0.4228% となり、`lora_r = 16` の約半分になった。

#### 結果

##### 学習結果

| 指標 | `lora_r = 16` | `lora_r = 8` |
|---|---:|---:|
| 学習時間 | 216 秒 | 218 秒 |
| 最終 Training Loss | 0.013844 | 0.013103 |
| `format_rate` | 1.000000 | 1.000000 |
| `content_rate` | 0.904762 | 0.857143 |
| `both_rate` | 0.904762 | 0.857143 |
| `regressed` | なし | なし |

どちらの設定でも、学習後の `format_rate` は 1.0 となり、JSON 形式はすべて正しく出力できた。

一方、内容の正確さを示す `content_rate` と、形式・内容の両方を満たす `both_rate` は、`lora_r = 16` の方が高かった。

- `lora_r = 16`：`content_rate = 0.904762`
- `lora_r = 8`：`content_rate = 0.857143`

最終 Training Loss は `lora_r = 8` の方がわずかに低かったが、評価データに対する内容の正解率は `lora_r = 16` の方が高かった。したがって、今回の実験では、学習可能パラメータ数は増えるものの、`lora_r = 16` の方が全体的な性能は良かった。

##### 4bit 量子化の比較

学習を行わず、推論時の基盤モデルだけを 4bit 量子化した場合の結果も確認した。

| 条件 | `format_rate` | `content_rate` | `both_rate` | 推論時間 |
|---|---:|---:|---:|---:|
| `lora_r = 16` の量子化前 | 0.142857 | 0.047619 | 0.047619 | 17.7 秒 |

4bit 量子化により、今回の評価では `format_rate` が改善した。ただし、4bit の結果は量子化のみを行った学習前モデルの結果であり、LoRA 学習後の結果とは直接比較できない。量子化によってモデルの出力が変化するため、量子化の影響と学習の影響を分けて評価する必要がある。

### 実装課題

#### 取り組んだレベル

実装レベルに取り組んだ。

『第2回 基盤モデルの仕組み』の課題内容に従い、FAQ・GROUNDED・UNGROUNDED の内容を図書館に関する情報へ置き換え、学習前後の出力を比較した。JSON の形式と `needs_review` の設計は変更しなかった。

#### 変えた設定やデータ

図書館に関する以下の 5 項目を FAQ として使用した。

```python
FAQ = {
    "opening_hours": "図書館の開館時間は平日 9:00〜21:00、土曜日 10:00〜17:00 です。",
    "closed_day": "図書館の休館日は日曜日と祝日です。",
    "borrowing_period": "図書の貸出期間は 14 日間です。",
    "maximum_books": "学生は一度に 5 冊まで借りられます。",
    "return_location": "図書は図書館入口の返却ポスト、またはカウンターで返却できます。",
}
```

LoRA の学習設定は以下のとおりである。

| 設定 | 値 |
|---|---:|
| ベースモデル | Qwen/Qwen3.5-0.8B |
| 学習方法 | LoRA（量子化なし） |
| `lora_r` | 16 |
| `lora_alpha` | 32 |
| 学習率 | 0.0002 |
| エポック数 | 20 |
| ステップ数 | 40 |
| 最大系列長 | 512 |
| 最大生成トークン数 | 96 |
| 学習時間 | 191 秒 |

学習可能パラメータ数は 6,389,760 個で、全パラメータに占める割合は 0.8421% だった。

また、FAQ に記載されていない「根拠なし」の質問として、以下を用意した。

- 図書館の住所を教えてください。
- 延滞すると延滞料金は発生しますか。
- 図書館は何階建てですか。

これらの質問に対しては、情報を推測して断定せず、以下のように `needs_review: true` を付けた回答を返すことを期待した。

```json
{
  "answer": "この FAQ には記載がありません。運営に確認が必要です。",
  "needs_review": true
}
```

#### 結果

##### 学習結果

| 指標 | 学習前 | 学習前・4bit 量子化 | 学習後 |
|---|---:|---:|---:|
| `format_rate` | 0.333333 | 0.666667 | 1.000000 |
| `content_rate` | 0.095238 | 0.095238 | 0.904762 |
| `both_rate` | 0.095238 | 0.095238 | 0.904762 |
| 推論時間 | 17.7 秒 | 32.5 秒 | 56.1 秒 |

学習後は、JSON 形式の正しさを示す `format_rate` が 0.333333 から 1.000000 に改善した。また、内容の正確さを示す `content_rate` は 0.095238 から 0.904762 に改善し、形式と内容の両方を満たす `both_rate` も 0.904762 となった。

学習前は、FAQ に記載されている質問に対しても正確に回答できない場合があった。例えば、「図書館の休館日はいつですか」という質問に対して、学習前は次のような誤った回答になっていた。

```json
{
  "answer": "月",
  "needs_review": false
}
```

学習後は、FAQ の内容に基づいて次のように正しく回答できた。

```json
{
  "answer": "図書館の休館日は日曜日と祝日です。",
  "needs_review": false
}
```

また、FAQ に記載されていない質問についても、学習後は情報がないことを示し、確認を促す出力になった。

```json
{
  "answer": "この FAQ には記載がありません。運営に確認が必要です。",
  "needs_review": true
}
```

以上の結果から、図書館 FAQ を用いた LoRA 学習によって、回答の JSON 形式と FAQ 内容への適合度の両方が大きく改善したことが確認できた。特に、根拠がない質問に対して無理に回答を生成せず、`needs_review: true` を付けて確認が必要であることを示せるようになった点が成果である。

一方で、評価データは 21 件と少ないため、今回の結果だけで一般的な質問への性能を判断することはできない。今後は、FAQ の文章を言い換えた質問や、学習時には使用していない質問を増やして評価する必要がある。また、4bit 量子化のみの場合は `format_rate` が 0.666667 に改善したものの、`content_rate` は 0.095238 のままだった。このことから、今回の内容理解の改善には、量子化よりも FAQ を用いた LoRA 学習の効果が大きかったと考えられる。

##### 「根拠なし」の質問の用意方法

FAQに記載されている5項目を確認し、そこから直接回答できない情報を尋ねる質問を自分で作成した。

具体的には、図書館に関する質問ではあるものの、用意したFAQには回答が書かれていない内容を選んだ。また、FAQにある質問の単なる言い換えにならないようにし、モデルがFAQの情報だけから推測して回答できない質問にした。

用意した「根拠なし」の質問は以下のとおりである。

- 図書館の住所を教えてください
- 延滞すると延滞料金は発生しますか
- 図書館は何階建てですか

例えば、FAQには開館時間や休館日、貸出期間、貸出冊数、返却場所についての情報はあるが、図書館の住所、延滞料金、建物の階数についての情報はない。そのため、これらの質問にはFAQだけを根拠に回答することができない。

このような質問に対しては、モデルが不確かな内容を推測して断定するのではなく、以下のように `needs_review: true` を設定し、確認が必要であることを示すようにした。

```json
{
  "answer": "この FAQ には記載がありません。運営に確認が必要です。",
  "needs_review": true
}
