## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  - 第1回の素のLLMは知識のない質問に対しては回答できない。一方で、今回のエージェントは、知識のない質問に対しても用語集から知識を検索することで、宿題の「3レベル」を「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」と説明した。いずれか1つのレベルに取り組めば宿題は完了で、原則として採点はないと回答した。最後に「第1回」と示した。
- `--trace` で見えたツール呼び出し：
  - 「LoRA と QLoRA の違いは？」では `search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` が呼ばれた。用語をそれぞれ検索し、用語集の定義に基づいて違いを回答した。
  - 確認問題の質問では `make_quiz({'lecture': 2})` が呼ばれた。返り値の例は次のとおりで、エージェントは問題文を提示した。

    ```json
    {"question": "「ランク（LoRAのr）」の意味は？", "answer": "LoRAで使う低ランク行列の大きさを決めるハイパーパラメータ。大きいほど表現力が上がるが、学習するパラメータとメモリも増える。"}
    ```

- 1つの質問での LLM 呼び出し回数（`requests`）：
  - LoRA と QLoRA の違いを尋ねた質問は `requests=2`（`tool_calls=2`）。
  - 確認問題を求めた質問も `requests=2`（`tool_calls=1`）。
- `--list-tools` で確認できたツール：`search_glossary`、`get_lecture_summary`、`make_quiz`。`make_quiz` の説明文と `lecture` 引数も表示された。
- 追加したツールと docstring の説明：`make_quiz(lecture: int) -> str` を追加し、指定した回の用語から1つを選んで確認問題と答えを返す。第2回の復習問題のように、確認問題を求められたときに使うことを説明した。
- テスト結果：`uv run pytest -q` を実行し、14件すべて成功した。
